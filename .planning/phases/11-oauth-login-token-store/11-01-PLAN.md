Token file JSON schema (version 1), one object, UTF-8:
  version: int (1)
  access_token: str (non-empty)
  refresh_token: str (non-empty)
  token_type: str ("Bearer")
  expires_at: float, absolute UTC epoch seconds (time.time() based)
  obtained_at: float, UTC epoch seconds
  granted_at: float, UTC epoch seconds of the browser consent (for 24-month expiry)
  site_id: str (non-empty; ints in the file are accepted and converted to str)

Module token_store (repo root, flat layout like solaredge_api.py):
  TOKEN_URL = "https://monitoringapi.solaredge.com/v2/oauth2/token"
  REFRESH_MARGIN_SECONDS = 300
  GRANT_MONTHS = 24 ; GRANT_WARN_DAYS = 30 ; HTTP_TIMEOUT = 10
  class LoginRequired(Exception): attribute reason: str (short, no secrets, e.g. "token file missing", "token file corrupt", "refresh rejected (HTTP 400)", "client credentials missing", "API rejected token after refresh")
  class TransientAuthError(Exception)
  @dataclass(frozen=True) class TokenData: access_token, refresh_token, token_type, expires_at, obtained_at, granted_at, site_id ; classmethod from_dict(d) -> TokenData (raises ValueError on schema problems) ; to_dict() -> dict incl. version=1 ; __repr__ must NOT include token values (use field(repr=False) on access_token and refresh_token)
  class TokenStore:
    __init__(self, token_file: str | Path, client_id: str, client_secret: str, env_file: str | Path | None = None)
    lock_file property -> Path(token_file.parent / (token_file.name + ".lock"))
    load(self) -> TokenData   (raises LoginRequired)
    save(self, data: TokenData) -> None   (atomic, 0600; raises OSError on failure)
    site_id property -> str   (load().site_id)
    get_access_token(self, now: float | None = None) -> str   (raises LoginRequired / TransientAuthError)
    force_refresh(self, rejected_access_token: str, now: float | None = None) -> str
    authorized_request(self, method: str, url: str, **kwargs) -> requests.Response
    reload_credentials(self) -> None   (re-reads SOLAREDGE_CLIENT_ID / SOLAREDGE_CLIENT_SECRET from env_file via dotenv.dotenv_values when env_file exists)
    warn_if_grant_expiring(self, now: float | None = None) -> None
  class TokenFileWatcher:
    __init__(self, *paths: str | Path)
    reset(self) -> None        (take current snapshot as baseline)
    has_changed(self) -> bool  (True if any path's (st_ino, st_mtime_ns, st_size) or existence differs from baseline; updates baseline)

Existing style to copy (solaredge_api.py _request): requests with timeout=10, catch requests.exceptions.Timeout / HTTPError / RequestException, log with logging.error(f"..."), English log text.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Pi process → SolarEdge token endpoint | Client secret and refresh token leave the device over HTTPS |
| Disk ↔ process | Token file on SD card holds long-lived refresh token |
| Concurrent processes on the Pi | Service + manual debug run may both try to refresh |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01 | Information disclosure | token_store logging | mitigate | No token/secret/response body in any log call; TokenData repr hides tokens; test asserts captured log records contain none of them |
| T-11-02 | Information disclosure | .tokens.json on disk | mitigate | mkstemp + os.fchmod 0o600 before writing; lock file created 0o600 |
| T-11-03 | Tampering / DoS | partial write on crash | mitigate | tmp + flush + fsync + os.replace + dir fsync; test simulates os.replace failure and asserts old file intact |
| T-11-04 | DoS (lost token chain) | two refreshers race | mitigate | fcntl.flock on separate lock file, re-load under lock before POST; thread race test asserts single POST |
| T-11-05 | DoS (lost token chain) | using unpersisted rotated token | mitigate | save() before return; save failure raises TransientAuthError, token not used |
| T-11-06 | Spoofing | token endpoint TLS | accept | requests default certificate verification stays on (never pass verify=False) |
| T-11-07 | DoS (credit burn) | retry loop on rejected refresh | mitigate | 400/401 → LoginRequired immediately, no retry; plain Session without urllib3 Retry |
</threat_model>
