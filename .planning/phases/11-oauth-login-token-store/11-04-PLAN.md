<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Token file on disk → main loop | Untrusted/corrupt content decides between data mode and login mode |
| Main loop → SolarEdge | Calls must stop when the token is unusable |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-19 | DoS (crash loop) | startup without token | mitigate | load() wrapped; LoginRequired enters login state instead of exiting; smoke test asserts returncode 0 and no Traceback |
| T-11-20 | DoS (credit burn) | calls during login state | mitigate | Login branch `continue`s before poll; smoke test asserts no API/refresh log lines (D-09) |
| T-11-21 | Information disclosure | logs | mitigate | Only LoginRequired.reason and fixed strings logged; grep gate forbids access_token in log calls (D-16) |
| T-11-22 | Tampering (misleading data) | stale rotation | mitigate | No screen cycle in login state; smoke test asserts only one login PNG rendered (D-08) |
| T-11-23 | DoS (token chain) | refresh while asleep / concurrent | mitigate | Token checks placed after the sleep-window block; concurrency handled by flock in token_store |
</threat_model>
