| API response → parser | Untrusted JSON shapes (nullable fields, unknown units, extra meters) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-08 | Denial of service (credit exhaustion) | SolarEdgeAPI._request | mitigate | retry defaults to False; only get_overview(retry=True) may make a second attempt, only on 5xx/Timeout with one 2 s sleep; all other jobs one attempt; 429/403/400/404 never retried; tests assert call_count per method |
| T-12-09 | Information disclosure | logging in solaredge_api.py | mitigate | Log path templates with literal "{site_id}", counts only, never bodies/params/serial keys; assertLogs hygiene test with fake id and serial |
| T-12-10 | Elevation / auth confusion | LoginRequired handling | mitigate | LoginRequired is not caught in _request; it propagates to main.py which shows "Login nötig" (Phase 11 D-07) |
| T-12-11 | Tampering / malformed input | parsers | mitigate | try/except (KeyError, ValueError, TypeError, AttributeError) → None; unknown unit → ValueError → None; caller keeps cached values |
| T-12-12 | Information disclosure | tokens | mitigate | Client never reads or logs tokens; Authorization header is set only inside TokenStore.authorized_request |
